The five core perf changes that landed this slice: (1) `crd::math::simd::fma(a,b,c)` single-rounded IEEE 754 FMA on Vec8f + Vec4d (ADR-0063 still respects two-rounded `mul_add` for eylem); (2) hesap GEMM microkernel + `simd_dot_*` / `simd_sumsq_*` helpers use `fma()` for ~2× FMA-port throughput; (3) Mc auto-tune + small_gemm_parallel direct unpacked fast-path; (4) classic BLAS single-pass symv (each lower-half element touched once → updates both y[i] and y[k] — halves memory bandwidth); (5) 8-row tiled gemv + 16-wide-unroll symv with 4 dot accumulators + gated `_mm_prefetch(_T1)` on next row of A (only when `n > 512`).
