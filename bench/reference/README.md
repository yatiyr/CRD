# Peer reference sources

Jonathan Richard Shewchuk's `shewchuk-predicates.c` is the preserved public-domain reference implementation
formerly kept at `scripts/.shewchuk-predicates.c`. Its original attribution and license statement remain in
the source. It is reference/oracle material, not a Cerid engine implementation or an automatically built target.

Reusable benchmark harnesses stay versioned. Put run output under `build/<task>/` and measured boards under
`docs/bench/`; follow `docs/bench/README.md` before making performance claims.
