## What shipped (per slice)

- **v11-g IIR digital design** (`iir_design.hpp`) — the unified design surface, faithful scipy:
  - `lp2hp_zpk` / `lp2bp_zpk` / `lp2bs_zpk` analog frequency transforms.
  - `iirfilter` (the dispatcher: prototype-by-kind → prewarp → band transform → bilinear) + `iirdesign` (spec → `*ord` → iirfilter).
  - Order estimation `buttord` / `cheb1ord` / `cheb2ord` / `ellipord` — including a **faithful `fminbound` (Brent
    bounded) port** for the bandpass band-edge optimization, and `band_stop_obj`. `ellipord` reuses the v11-f `ellipk`.
  - `iirnotch` / `iirpeak` / `iircomb` (tf — inherently 2nd-order / sparse, well-conditioned).
  - **Gate**: response-equality vs scipy `output='sos'` (|H| 64 pts 1e-9) for hp/bp/bs designs; **exact N** + Wn +
    **spec-compliance** (the designed filter meets gpass@wp, gstop@ws) for order-est; coeffs vs scipy for notch/peak/comb.
  - ⭐ The spec-compliance gate **caught a real `band_type_of` bug**: scipy's bandpass spec has the passband *inside*
    the stopband (`wp[0] >= ws[0]`); my 2-element branch was inverted. N/Wn matched (the `filter_type` math was right);
    only the band-type inference for the spec design was wrong — exactly the kind of bug a property gate catches that a
    coefficient gate would not.
- **v11-h RBJ audio biquads** (`rbj.hpp`) — the DAW cookbook: lowpass / highpass / bandpass(0 dB) / notch / allpass /
  peaking / low-shelf / high-shelf + a cascade EQ. **Raw f64, `f0` as a Nyquist fraction** — consistent with the rest
  of the hesap-dsp kernel layer (ADR-0078 lower layer; typed `Frequency`/dB wrapping is a DAW consumer's job, not the
  kernel's). **Gate**: coeffs vs an *independent* python cookbook transcription (1e-12) + the spec properties (DC /
  Nyquist / centre-frequency gains, allpass unity, peaking/shelf gains, a 4-band EQ chain).
- **v11-l Hilbert** (`hilbert.hpp`) — `hilbert` (analytic signal: **pow-2 fast path via `FftPlan`, any length via
  `BluesteinPlan`**) + `envelope` + `instantaneous_phase` (numpy `unwrap`) + `instantaneous_frequency` + a plan-cached
  **`HilbertTransformer`** (the streaming hot path). **Gate**: real+imag vs scipy 1e-10 (even + odd length) + the
  analytic property (Re == x) + a linear chirp's instantaneous frequency vs scipy + the physical sweep.
- **v11-k multirate** (`multirate.hpp`) — `upfirdn` (polyphase, **reversed per-phase tap bank** ⇒ a branch-free
  contiguous dot product) + `resample_poly` (Kaiser-firwin anti-alias, faithful scipy padding/trim arithmetic incl.
  `_output_len`) + `decimate` (FIR zero-phase). **Gate**: vs scipy `upfirdn`/`resample_poly`/`decimate` 1e-9/1e-12 +
  the run-twice determinism moat (single-thread, fixed tap order ⇒ bit-identical across runs).
- **v11-r waveforms** (`waveforms.hpp`) — `chirp` (linear/quadratic/logarithmic/hyperbolic, faithful scipy
  `_chirp_phase`) + `sawtooth` + `square` + `gausspulse` + `sweep_poly` (polynomial-integral instantaneous frequency)
  + `unit_impulse`. Generators (one-time) ⇒ correctness only (vs scipy ~1e-10 on identical time vectors), no perf
  bench (the honest-gate rule, as windows). MLS/Gold/Kasami sequences = follow-on.
- **v11-t adaptive** (`adaptive.hpp`) — `LmsFilter` / `NlmsFilter` / `SignLmsFilter` / `RlsFilter` (alloc-free
  stateful streaming kernels — the system-ID/echo-cancel/equalization hot loop, run-twice bit-deterministic) +
  `wiener_hopf` (batch optimal, Toeplitz autocorrelation method + Gaussian elimination). **Gate**: known-plant
  recovery (each filter converges to a planted FIR from a deterministic input — convergence IS the spec, self-
  contained) + Wiener-Hopf = the finite-sample normal-equation solution + run-twice determinism. ⚠ the Wiener-Hopf
  recovery is finite-sample (autocorrelation-method window bias ~1/N, asymptotically exact) — relaxed the gate from
  a too-tight 1e-8 to 1e-3 (the RLS covariance-LS path recovers to 1e-6). Affine-projection = follow-on.
- **v11-o AR** (`ar.hpp`) — `aryule` (biased autocorrelation + Levinson-Durbin) + `arburg` + `ar_psd` + `ar_aic`/
  `ar_mdl`. **Gate**: recover a known AR(2) process (both methods) + reflection |k|<1 + AR-PSD peak at the resonance
  + AIC/MDL pick the true order. ⭐ the recovery gate **caught a Burg backward-error index bug** (the new b_m[n] was
  stored at b[n-1] instead of b[n]). Self-contained.
- **v11-q transforms** (`transforms.hpp`) — `goertzel` (single-bin DFT) + `czt` (chirp-z / zoom-FFT over the v10 FFT)
  + `rceps`/`cceps` (cepstrum) + `fwht` (fast Walsh-Hadamard). **Gate**: Goertzel == the direct DFT bin; czt(default)
  == DFT + a zoom arc == the direct sum; rceps recovers an echo delay; fwht self-inverse. ⭐ caught a Goertzel
  output-formula bug (`e^{jw}·s1 − s2`, not what I first wrote). Self-contained.
- **v11-p subspace** (`subspace.hpp`) — `music_spectrum` + `root_music` over the noise subspace of the biased-
  autocorrelation covariance (crd-hesap-dense `eig_sym` + polynomial `roots`). ⭐⭐ **Gate = super-resolution**: resolve
  two tones Δf=0.006 apart, BELOW the FFT bin 1/128≈0.0078 — the resolution a periodogram cannot reach. ESPRIT (needs
  a general eig) = follow-on. Self-contained.
- **v11-n multitaper** (`multitaper.hpp`) — `multitaper_psd`: the average of K DPSS-tapered periodograms (the top-K
  eig_sym eigenvectors of the Slepian tridiagonal; rFFT eigenspectra). **Gate**: a tone gives a sharp peak + the
  K-taper estimate has lower variance than a single periodogram. Accuracy-gated (the crush is variance-reduction, not
  throughput — the taper setup is eig_sym-bound; an efficient K-taper DPSS + adaptive weighting + the parallel FFT
  moat = follow-ons). Self-contained.

CZT loses to scipy (scipy shortcuts the M=N DFT case + caches the chirp-FFT plan; Cerid runs the general chirp-
convolution and rebuilds 3 transient FFT plans/call — the FftConvolver/HilbertTransformer lesson; a plan-cached
`CztPlan` is the follow-on, the transform is correct to 1e-9) but beats MATLAB 3.59×. Multitaper + root-MUSIC are
accuracy-gated (super-resolution / variance-reduction is the win, not throughput).

- **resample_poly EARNED** the win: the first cut (per-tap bounds checks: `k>=lh`, `xi<0`, `xi<n`) **LOST** 0.84×/0.69×
  to scipy. The reversed polyphase bank + a precomputed valid range (branch-free contiguous dot) flipped it to a win —
  the "measure → honest loss → find the real lever → win" pattern. liquid's rresamp is f32 (Cerid is f64 — an accuracy
  advantage, flagged).
- **Hilbert**: the one-shot `hilbert()` **loses** to scipy/MATLAB (rebuilds the full FFT twiddle table per call — the
  v11-j FftConvolver lesson). The plan-cached `HilbertTransformer` (the realistic streaming hot path) **beats both** —
  Cerid's FFT execute > PocketFFT. Both stories reported honestly in the bench source.
