# 2026-07-25 — REN-2 Half A: render-to-texture transients (D-007 row 99)

**Slice**: make the frame graph's `sampled` transients first-class DRAWN-THROUGH — a pass renders into a
transient color image, a LATER pass SAMPLES it as a texture. This is the render-to-texture (RTT) half of REN-2;
the material-texture half (Half B) is the remaining REN-2 work. **Both backends, gated, tidy — no deferral.**

## The load-bearing reuse: `draw_wboit` already proved RTT

`draw_wboit` renders into a `COLOR_ATTACHMENT|SAMPLED` image, barriers it `COLOR_ATTACHMENT→SHADER_READ_ONLY`,
and samples it in a composite pass. REN-2 generalizes that exact sequence into the frame graph's transient system
— I didn't invent the hard part. Spec: `docs/design/ren-2-rtt-and-material-textures.md`.

## What shipped (Vulkan)

- **Borrowed transient wrappers**: a `m_borrowed` flag on `VulkanRasterTarget` + `VulkanTexture` — their dtors
  `destroy_image_bundle`, so a transient (whose aliased memory the frame-graph slot owns) must skip that, else a
  double-free with `free_transients`. `build()` now constructs a borrowed `VulkanRasterTarget` over the
  graph-owned `{image, view}` (no memory, no readback); a `sampled` transient also gets a borrowed `VulkanTexture`.
- **`record_offscreen`** (branch of `draw_storage`) — a color-only render into the transient (no depth, no
  readback), into the shared command buffer. **`record_textured`** (branch of `draw_sampled`) — bind a SAMPLED
  image (binding 1) + sampler (binding 2) from the frame descriptor pool, color-render into the target. Both
  mirror REN-1's `record_scene`.
- **`execute()`** inserts the RTT barrier: a written transient → `COLOR_ATTACHMENT_OPTIMAL`; when a later pass
  reads it → `COLOR_ATTACHMENT → SHADER_READ_ONLY_OPTIMAL`. `texture(FgImage)` resolves the borrowed texture.

## What shipped (DX12 — the mirror, no deferral)

- ComPtr refcounting means NO borrowed flag is needed: a borrowed `Dx12RasterTarget` (its own single-RTV heap) +
  `Dx12Texture` SRV just hold a ref to the placed transient resource; `free_transients` deletes the wrappers then
  releases the resource + heap.
- `frame_rec_begin` now binds BOTH the frame heap and the sampler heap. `frame_alloc_srv_slot` writes an SRV into
  the per-draw frame-heap ring (REN-1's ring); `record_offscreen`/`record_textured` bind it at root table 1 +
  the sampler at table 2. The RTT barrier is `RENDER_TARGET → PIXEL_SHADER_RESOURCE`.

## Gates (both backends, `[ren2]`)

A two-pass graph: pass "offscreen" `writes(rtt)` renders a red triangle over a green clear into a `sampled`
transient; pass "compose" `reads(rtt)` full-screen-SAMPLES it into the final target. Readback of the final:
**centre = RED** (sampled from the transient's red-triangle centre), **corner = GREEN** (sampled from the green
clear) — the round-trip is faithful, NOT the blue compose clear. ONE submission, RTT barrier counted.
- Vulkan (`test_vulkan_frame_graph.cpp`): **14 asserts**, validation-SILENT (0/0); full frame-graph suite **47**.
- DX12 (`test_dx12_frame_graph.cpp`): **13 asserts**; full DX12 suite **1041**, zero regression.
- All four touched files tidy-clean.

## Scars / decisions

- **Vulkan needs the explicit borrowed flag; DX12 doesn't** — Vulkan handles aren't refcounted (the wrapper dtor
  would free the graph-owned image), DX12's ComPtr is.
- **Offscreen uses `draw_storage` (color-only), not `draw_storage_depth`** — an RTT color transient needs no depth
  attachment (matching `draw_wboit`), so branching the color-only `draw_storage` avoids giving every transient a
  depth image.
- **DX12 records must bind the sampler heap** — `record_textured`'s root table 2 samples from `m_sampler_heap`, so
  `frame_rec_begin` binds it alongside the frame heap (one CBV_SRV_UAV + one sampler heap, DX12's max).

## Half B — the textured forward draw (device capability, both backends)

Pushed straight on into Half B. The forward pass can now SAMPLE a material texture:
- **Interface** (appended at END): `draw_storage_textured_depth` / `_load` — bind storage(0) + a base-color
  SRV(1) + sampler(2) in ONE descriptor set, so a vertex-pulled mesh samples its albedo map at the pulled UV
  instead of a flat colour. Default (backends without it) drops the texture ⇒ flat fallback, never absent.
- **Vulkan**: `write_scene_textured` (the 3-binding set) + `record_scene_textured` (frame-recording, depth-tested,
  clear or load) + a standalone path; the SceneRenderer's textured forward pass records through the frame graph.
- **DX12**: the mirror — storage UAV + base-color SRV both from the per-draw frame-heap ring + the sampler heap
  (recording), or heap slots 0/1 + the sampler heap (standalone).
- **Shared shader** `build_pull_textured_vs`/`_fs` (pull {x,y,z,u,v}, sample base-color at UV).
- **Gates GREEN** (`[ren2][material]`): a full-screen mesh over a 2×1 left-red/right-green base-color map →
  screen-left samples RED, screen-right GREEN (the forward pass SAMPLED the map, not the flat/blue clear).
  Vulkan validation-silent, 11 asserts (frame-graph+material suite 75); DX12 10 asserts (full suite 1051);
  all six touched files tidy-clean.

### The SceneRenderer wiring (done)

The forward pass now consumes the device capability:
- `build_scene_vs_textured` / `build_scene_fs_textured` — the flat scene shaders + the vertex's uv0 (48-byte record
  words 6-7) emitted/sampled; output = albedo · per-instance tint · N·L lighting.
- `Impl::resolve_base_color_texture(material)` — load the `OpenPbrMaterial`, follow `textures.base_color` to the
  cooked `TextureResource`, upload its mip chain via `create_texture_from_mips`; cached per material.
- `MeshGroup` gains a representative `material` (first instance's); the draw loop selects the TEXTURED program +
  `draw_storage_textured_depth` for groups whose material carries a base-color map, else the flat path. Skinned is
  unchanged; per-instance material textures (a mesh with mixed materials) are a **bindless follow-up**.
- **Compiles + tidy-clean; scene-render suite 58/5 GREEN — the GEO-7 10k flat path is intact (no regression).**
