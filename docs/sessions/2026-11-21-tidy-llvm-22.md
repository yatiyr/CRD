## What landed

- The pin: `tools/llvm` is LLVM 22.1.8's Windows archive and `tools/clang-tidy-linux` PyPI's 22.1.8 wheel (both
  digests GitHub's and PyPI's own); the gate requires major 22 and looks for `install-clang-tidy.py`'s install below
  the home directory on every host (USERPROFILE on Windows, where it was `C:/LLVM-20.1.8`).
- A survey of all 2,064 win-tidy units with 22 found 148 findings in 11 checks (none in hesap-ordering or
  hesap-direct). Fixed: strict numbers in ceridc's and kir-autotune's flags (any text was 0) through a new crd-core
  capability, text.parse-integer, which also replaces the digit loops of ceir-cook and perf, the `from_chars` of CEIR
  text, the environment and the Matrix Market reader (whose `max` check let a digit past a bound under 9 through);
  `noexcept` wrappers that could throw (`filesystem.cpp`, two test mains, a destructor, a hang handler); throwing
  static tables; overrides made private; four unscoped index enums; float loop counters; ambiguous `reset()`;
  confusable names; redundant parentheses. ceridc's tests run the binary through one shell helper.
- Declined: `misc-multiple-inheritance` (22's name for fuchsia-multiple-inheritance, never enabled; the frame-graph
  interfaces have default members by design), reasoned in `.clang-tidy`.
