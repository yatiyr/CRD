## Evidence

- `crd-net-tests [hpack]`, 20 cases and about 24,600 assertions: linux-gcc-debug, linux-gcc-asan, linux-clang-tsan, linux-gcc-release (LTO) and win-debug (MSVC) pass, with `[qpack]` after the table's move; `[http3]`, `[websocket]` and `[webtransport]` on debug and ASan. RFC 7541 appendix C.2 to C.6 with the table states, and C.4 byte for byte from the encoder. Tidy clean on every file the tidy gate sees, through a compile database with the PCH flags removed.
- **Interop:** all 446 stories of the corpus's fourteen encoder runs (nghttp2 at three settings, Go, node-http2, python-hpack, swift-nio, Haskell's six) decode to the story's fields exactly, size updates included.
- **Compactness:** 1.1% above nghttp2 and 0.85% above python-hpack, all of it the rule that cookies are never indexed; 0.5 to 0.7% below them with that rule dropped for one build ([board](../bench/2026-11-09-4-2a-hpack-compression.md)).
- **Fuzz:** `crd-fuzz-net-hpack` on linux-clang-fuzz: 1,489,686 executions over three clean sessions (corpus 3 to about 2,300 units), no finding. The other four of the seven sessions ended in crashes that do not replay: a UBSan null `this` on an atomic constructor, a SEGV reading a local `String`, a zero-page write and a stack-buffer-overflow read of a local span. Each crash file ran clean on the same binary and none is adopted. They resemble this host's misexecution record (`docs/design/test-instruments.md`), but the rate is above its usual one run in ten, so `net-hpack` joins `host-check.yml`: hosted rounds decide, and a hosted event is a defect.
- **Mutations:** 43 source mutations of `hpack.cpp` and the output: 40 fail the tests and pass once restored. One is equivalent (index 0 also fails the dynamic bound by wrap-around); two showed code that did nothing and it went: a per-line check for an owed size update that the end of the block repeats, and a mask that could only be one value. Two survivors at first (a size update said on every later block; a Huffman line after the storage ran out) each gained a test and now fail.
