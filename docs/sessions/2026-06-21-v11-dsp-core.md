## What shipped (per slice)

- **v11-a substrate** — reps tf/zpk/**SOS**/state-space/lattice + all conversions (zpk↔tf · zpk→sos nearest-to-unit-
  circle pairing · sos→tf · tf↔ss controllable-canonical + Faddeev-LeVerrier · denom↔lattice Levinson) +
  `freqz`/`sosfreqz`/`zpk_freqz`/`group_delay`. **`crd-units`** gained `DecibelRatio`/`DecibelPower` (the existing
  *nonlinear* dB lens extended — NOT a wrong "linear Decibel") + `NormalizedFrequency`. ⭐ **Data-flow rule LOCKED**
  (advisor-caught): filters are designed in zpk → sos *directly*; tf is output-only (roots-of-tf is Wilkinson-ill-
  conditioned >order ~8, proven by an order-12 conditioning gate). N-digit design tolerance = **10 sig digits**.
- **v11-b windows** — 24 windows (cosine-sum via one `general_cosine` + simple + periodic + Kaiser/gaussian/tukey +
  Taylor + **Dolph-Chebyshev** via FFT + **DPSS/Slepian** via `dense::eig_sym`, scipy 'approximate' norm reverse-
  engineered from source). vs scipy 1e-10…1e-13.
- **v11-c FIR windowed** — `firwin` + `firwin2` (closed-form ⇒ full 1e-12 match).
- **v11-d FIR optimal** — `firls` (Toeplitz+Hankel normal-eqn + LU) + **Parks-McClellan `remez`** (the full exchange:
  dense grid + barycentric-Lagrange + closed-form δ + extremal search/exchange + DCT-I final coeffs; equiripple,
  spec-compliance gate) + Savitzky-Golay + raised-cosine/RRC. Remez worked first try.
- **v11-e IIR analog prototypes** — `buttap`/`cheb1ap`/`cheb2ap`/`besselap` + `bilinear_zpk`/`lp2lp_zpk` + digital
  `butter`/`cheby1`/`cheby2`/`bessel`. Bessel = reverse-Bessel-polynomial θ_N roots via companion+eig (= scipy
  'delay' exactly).
- **v11-f ELLIPTIC (Cauer)** — the elite-hard slice, shipped **first try via bottom-up independent gating**: the
  special-function substrate `ellipk` (AGM) / `ellipj` (descending Landen) / `ellipdeg` (nome + theta series) /
  `arc_jac_sc` (complex ascending Landen, crd-`Complex` csqrt/casin/clog) each gated vs scipy.special *before*
  composing `ellipap`/`ellip`.
- **v11-i filtering + streaming** (the two-layer LOWER layer) — `sosfilt_stream` (alloc-free stateful DF2T biquad
  cascade) + `sosfilt`/`sosfiltfilt` + `lfilter`/`lfilter_zi`/`filtfilt`. **Bit-exact vs scipy** + the **streaming
  moat** (arbitrary block sizes == one batch call, bit-identical memcmp).
- **v11-j convolution** — `convolve` (direct) + `fftconvolve` (real-FFT path) + **`FftConvolver`** (plan-cached) +
  `correlate` + `oaconvolve` + `deconvolve` + `matched_filter`.
- **v11-m spectral** — `welch_psd` + `spectrogram` + `stft`/`istft` (perfect reconstruction) + `periodogram` +
  `csd` + `coherence`. ⭐⭐ **THE MULTI-THREADED FFT**: Welch's per-segment FFTs are independent ⇒ `crd::jobs::
  parallel_for` with per-job `RealFftPlan`s (built serially up front, no thread-safe-alloc) + a **serial fixed-order
  average** ⇒ the PSD is **bit-identical across {1,2,4,8,16} threads** — a determinism moat MKL/FFTW lack.

## Honest corrections the user forced (and that improved the work)

1. **No cherry-picking peers.** Caught benchmarking fftconvolve vs scipy only (a 1.15× "win") while skipping MATLAB
   (which won). Rule written to memory; the full board is now always run. → `feedback_bench_all_peers_never_cherry_pick`.
2. **"It's the MKL backend" was WRONG.** The fftconvolve slowdown was **profiled**, not excused: it rebuilt the FFT
   plan (28 ms twiddle precompute) *every call*. The raw FFT is fast (12.7 ms). Fix = `FftConvolver` (plan cached)
   ⇒ 2.1× scipy. Lesson: a 5×-too-slow op next to a fast raw kernel screams *overhead*, not kernel.
3. **NO std owning containers ANYWHERE, tests included.** Purged `std::map`/`string`/`vector`/`pair` from all 5 v11
   test-reference `.inc` files (→ plain C arrays `inline const double ref_x[]`) and all test helpers (→
   `template<usize N> check(const double(&)[N], …)`). Verified grep-clean. → `feedback_no_std_containers_anywhere_incl_tests`.

## Bugs caught by the gates (impl correct in some, ref wrong in others)

- order-12 conditioning gate proved the zpk→sos data-flow rule (and drove the nearest-pairing upgrade).
- `lfilter` last-bit drift → matched scipy's exact `b·x + z − a·y` association ⇒ bit-exact.
- `csd` imaginary sign → scipy uses `conj(X)·Y`, not `X·conj(Y)`.
- DPSS normalization → scipy default for Kmax=None is 'approximate' (`/max ×M²/(M²+NW)`), reverse-engineered.
- Several test-reference sign/formula bugs (one-pole H.im, group-delay τ, periodogram DC detrend) — impl was right.
