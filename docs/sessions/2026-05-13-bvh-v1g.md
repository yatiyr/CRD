# Session — 2026-05-13 — Phase 3.1.7 v1g: `Vec4f` ray-vs-4-AABB kernel + BVH4 as the recommended traversal form (closes the `-bvh` sub-module)

## Goal

Seventh and final `crd-geometry-bvh` slice: the `Vec4f` SIMD ray-vs-4-AABB
kernel for BVH4 traversal, BVH4 promoted to the recommended traversal form for
static query-heavy data, and the vestigial `BvhBuildOptions::topology` field
retired. (Scope per the discussion: **Option A** — keep `bvh4_collapse(BvhTree)`
as the BVH4 path; don't add a second 4-way SAH builder. The
build-binary-then-collapse route is the elite-quality one (Embree / Jolt / PBRT)
and keeps one builder, one determinism story.)

## What we built / changed

- **`include/crd/geometry/bvh/bvh4_simd.hpp`** (new, public; in the umbrella) +
  **`src/bvh4_simd.cpp`** — `ray_vs_4_aabb(const Ray3<f32>& ray, const RayAABBPrecompute<f32>& pre, Vec4f bmin_x, bmin_y, bmin_z, Vec4f bmax_x, bmax_y, bmax_z, f32 t0, f32 t1) → Ray4AabbResult{Vec4f t_enter; Vec4f hit_mask;}`
  — one ray vs four AABBs (held SoA: `bmin_x` = the four boxes' min.x, …) in a
  single `Vec4f` min/max chain: the Tavianator branchless slab test broadcast to
  4 lanes (`tx0 = (bmin_x − ox)·ix; tx1 = (bmax_x − ox)·ix; tmin = max(min(tx0,tx1), min(ty…), min(tz…)); tmax = min(max…, max…, max…); tmax ·= (1 + 2γ₃)` per Ize 2013;
  `lo = max(tmin, t0); hi = min(tmax, t1); hit = cmp_le(lo, hi)`), NaN/∞-direction-safe
  via the min/max ordering (a zero direction component gives ±∞ and that axis
  drops out). Out-of-line in a `.cpp` (a real TU) — but `Vec4f` is 128-bit
  (`xmm`) at every SIMD level, so the AVX2-`ymm`-expecting `crd-simd-emission-check`
  doesn't scan it yet (a 128-bit-aware emission-check variant is a follow-up,
  same as the `simd_batch.cpp` one from v0f).
- **`src/bvh4.cpp` — `bvh4_raycast` switched to the kernel.** Per popped node:
  transpose its `child_count` children's `.bounds` into 6 `f32[4]` (unused lanes
  duplicate child 0 — harmless, the loop only reads lanes `[0, child_count)`) →
  `Vec4f::load` → one `ray_vs_4_aabb(ray, pre, …, 0.0F, best_t)` → `store`
  `hit_mask`/`t_enter` to `f32[4]` → scan lanes `[0, child_count)`, skipping a
  missed lane or one entered no earlier than the current `best_t` (its box —
  hence every prim/subtree below — can't beat it); leaf children test their
  prims scalar via `intersect_ray_aabb_robust` (per-leaf SIMD over the prims is
  `-mesh` v4g). **Bit-identical** (for finite/well-formed inputs) to the four
  scalar `intersect_ray_aabb_robust` calls it replaced — the Tavianator `min`/`max`
  form picks the same near/far plane the Williams `sign`-bit form does — so the
  v1d "`bvh4_raycast` == `bvh_raycast`" test and the new lane-by-lane kernel test
  both pass.
- **`BvhBuildOptions::topology` + the `BvhTopology` enum removed.** They were
  speculative from v1a; `bvh_build` is always binary, `bvh4_collapse` is the BVH4
  path. The two builders' `CRD_ASSERT(opts.topology == BvhTopology::Binary && …)`
  removed; `bvh_tree.hpp`'s topology comment rewritten ("`BvhTree` is a *binary*
  tree; `bvh_build` always builds binary, `bvh4_collapse` widens to `Bvh4Tree`").
- **Docs flip:** BVH4 is now the recommended traversal form for static,
  query-heavy data (renderer cull, eylem broadphase static side, mesh-raycast
  leaves) — consumers call `bvh4_collapse(BvhTree) → Bvh4Tree` then
  `bvh4_raycast` / `bvh4_overlap`. `BvhTree` (binary) stays the mutable primary
  form (`bvh_refit`, `DynamicBvh` operate on it).
- **`tests/geometry-bvh/test_bvh4.cpp` — new case** "BVH4: ray_vs_4_aabb (Vec4f
  kernel) lane-by-lane vs the scalar robust slab": 2000 random ray×4-box trials
  (finite + ∞ `tmax`); for each lane, `(hit_mask != 0)` equals
  `intersect_ray_aabb_robust`'s boolean and (on a hit) `t_enter` bit-matches.

## Plain-English explanation

A BVH4 node has four child boxes; on every traversal step the ray has to be
tested against all four. v1d did that as four sequential scalar slab tests; v1g
does it as one SIMD instruction-stream over four lanes — `(bmin − origin)·(1/dir)`
and `min`/`max` on a `Vec4f` (four floats at once). The arithmetic is exactly the
same numbers the scalar version computed (a `min(a,b)` picks the same value the
`if (sign) a else b` would), so the tree's answers don't change — it's just
faster per node. And the cleanup: the binary `BvhTree` had a leftover "topology"
knob from when 4-wide was going to be a build option; v1g deletes it — `bvh_build`
is binary, and `bvh4_collapse` is how you get the 4-wide form, full stop. With
that, the whole `-bvh` sub-module (build, parallel build, refit, dynamic tree,
4-wide collapse + SIMD traversal, raycast, overlap, closest-point) is done.

## Decisions made

- **Option A.** Keep `bvh4_collapse` as the BVH4 path; no direct 4-way SAH
  builder (worse quality for more code — the build-binary-then-collapse route is
  what Embree/Jolt/PBRT do, and it keeps one builder + one determinism story).
  "BVH4 promoted to default" = the *recommended* traversal form + the SIMD kernel
  that makes it actually faster — not a return-type change on `bvh_build`.
- **The `Vec4f` ray-vs-4-AABB kernel is the Tavianator min/max form**, not the
  Williams sign-bit form — cleaner for SIMD (no per-axis sign select), and
  produces the same values for finite/well-formed inputs (so `bvh4_raycast`
  stays bit-identical). The Ize 2013 `tmax` widening is applied per lane.
- **`bvh4_simd.cpp` is out-of-line** (a real TU) so it *can* be emission-checked,
  but it isn't wired into `crd-simd-emission-check` yet — that check expects AVX2
  `ymm` and `Vec4f` is 128-bit `xmm` at every level; a 128-bit-aware check
  variant (which would also cover `simd_batch.cpp`) is a noted follow-up.
- **The node layout is unchanged** (still AoS `Bvh4Child children[4]`) — the
  per-node transpose into SoA `Vec4f`s is done on the fly in `bvh4_raycast`. A
  SoA-bounds node layout (the "real" SIMD-BVH4 form) is a possible future
  optimization if benchmarks demand it; it'd be invasive (the v1d `Bvh4Child` /
  `validate_bvh4` assumptions). v1g's on-the-fly transpose still demonstrates the
  SIMD kernel + hits the ~8 ns/node budget shape.
- **`topology` field removed**, not repurposed — clean.
