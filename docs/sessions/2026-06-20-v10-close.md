## 2. v10-c Bluestein — arbitrary-size FFT (`bluestein.hpp`)

`BluesteinPlan<T>`: any n (prime/composite/non-pow-2) in O(n log n) via chirp-z over one pow-2 `FftPlan`
(M=2^⌈log2(2n−1)⌉; FFT_M(b) precomputed/shared; inverse via the forward-trick). The engine FFT is unnormalized
both ways, so the convolution folds an explicit 1/M — a real bug the brute-force-DFT gate caught. Machine-eps
(~1e-15) for n∈{3,5,7,17,1009,1031,…,10000}.

## 3. v10-e N-D FFT (`nd_fft.hpp`)

`NdFftPlan<T>`: arbitrary-rank row-column over the 1D engine — pow-2 axes → `FftPlan`, non-pow-2 → `BluesteinPlan`
⇒ ANY shape. Applies the FORWARD DFT only per axis (both engines agree on the unnormalized forward) and does the
inverse with the N-D forward-trick conj(FFT(conj·))/∏dᵢ, so the `FftPlan`-unnormalized vs `BluesteinPlan`-
normalized inverses never clash. Gate = a direct full N-D DFT (O(total²)) + round-trip, ~1e-16 for 2D/3D/4D incl.
non-pow-2 axes.

## 4. v10-h Sparse FFT (`sparse_fft.hpp`) — shipped, then upgraded to sub-linear + noise-robust

First pass: HIKP hashing + single-offset phase-ratio location + O(n) exact-coeff verification + peeling → exact
k-sparse recovery (~machine-eps). Then, on the user's "no follow-ons, implement them," **rewritten to be
end-to-end sub-linear AND noise-robust**:
- **Multi-scale binary location** — bucketize at log₂(n)+1 dyadic offsets; bit j of f is the sign of the
  low-bit-corrected β_j=2^{m−j−1} phase, each bit ±π/2-robust (replaces the noise-fragile single-offset ratio).
- **Voting + component-median** bucket estimation across rounds (no O(n) verify/peel — the O(n) steps are gone).

Result: recovery is O(R·log n·(w+B log B)) — no O(n) step (bucketize touches w=1.6–50% of n). Gates: exact
k-sparse (~1e-7) AND noisy k-sparse (σ≤0.008/bin → all frequencies recovered, coeffs to the √(n/B)·σ/√R floor).
Honest physics: the sub-linear-B regime is robust where bucket-SNR ≳ 10; machine-eps coeffs under noise need ~n
samples (information-theoretic).

## Decisions

- **ADR-0092:** deterministic plan-from-factorization; portable-C++ (no asm, ADR-0082); **MKL global parity
  DEFERRED** — production-grade portable FFT, not an MKL clone. The residual ~15% mid-size is the four-step
  inter-stage twiddle (8 measured rejected attempts), out of scope.
- Determinism is OFF the usual moat axis (an FFT has no thread-dependent reduction ⇒ {1..16} bit-identity is
  by-construction). No parallel-batched FFT API yet — a v10-e follow-on.
