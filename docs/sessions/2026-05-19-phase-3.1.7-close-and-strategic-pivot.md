## Part 2 — Strategic pivot (locked 2026-05-19 user direction)

Mid-session, the user locked three load-bearing architectural decisions
that change the medium-term roadmap.

### Decision 1: Agent-native engine

User mandate: "I want everything in the engine absolutely controllable
by cli commands. The reason I want that is to integrate AI agents like
you to our workflows for robotics, aerospace design, cinematics design,
game design by writing scripts, shaders and stuff and all the creative
tasks can be easily done by the ai agents in the future."

Locked artifacts:

- **`docs/research/cerid-agent-native-engine.md`** (~12 sections, ~500
  lines) — vision dossier covering 3-layer surface inversion, JSON-RPC
  + MCP exact compatibility, capability-based security, transactional
  sessions, replay determinism, per-domain agent integration trends
  (robotics, cinematic, aerospace, game, medical, DSP, sci-comp),
  reference patterns from VS Code LSP / Houdini hscript / Mujoco MJX /
  Roblox Studio.
- **`docs/decisions/0081-agent-native-engine-cli.md`** (Proposed; Accepted
  when `crd-cli` v0 ships) — supersedes ADR-0034 (folds C++ hot-reload
  in as a sub-aspect). 9 sections incl. §2 schema versioning, §6.4 MCP
  exact compatibility, §8.5 engine-wide CLI catalog (28 categories from
  assets through ML training).
- **`docs/PRINCIPLES.md`** — new cornerstone: "Agent-native engine:
  CLI / RPC is the source of truth."
- Memory entry `project_agent_native_engine_strategic_direction.md`.

### Decision 2: C++ hot-reload as the ONLY scripting language

User mandate: "For scripting language C++ hot reload MUST BE the choice
and we MUST have a CLI like scripting (OUR OWN CRD SCRIPTS POWERED BY
C++) this is my decision on that."

Locked artifacts:

- Original ADR-0081 §3 reference to Lua 5.4 removed.
- New PRINCIPLES.md cornerstone: "C++ hot-reload is the ONLY scripting
  language."
- ADR-0034 (C++ DLL hot-reload) **subsumed** by ADR-0081 as the
  scripting-substrate sub-aspect.
- Cerid scripts ARE C++ files (`.crds.cpp`) compiled into hot-reloadable
  DLLs. AI agents emit C++ → cooker compiles → hot-reload → call →
  inspect typed output → next iteration. One language for engine + tools
  + scripts + agents.
- Reference architectures pinned: Live++ (Molecular Matters), Anvil
  engine (RAD Game Tools), JetBrains C++ hot reload, RemedyBG.

crd-rpc are later in my opinion but we make low level plumbing for

### Decision 5 (derived): Phase 4.0 redefined

Phase 4.0 absorbs `crd-cli` + `crd-rpc` + `crd-script` into one

+ capability-based security + transactional sessions + sandbox
isolation + C++ hot-reload supervisor. Subsumes the original
Phase 4.0 = "C++ scripting / DLL hot-reload."

   `kBoundaryUlp` + `kCrossKindEps` + `world_sphere` (3 unused-var
   issues) all surfaced by clang-cl across this session. Pre-existing
   code can fail clang-cl when MSVC happily accepts. Worth a memory
