## What was built

### v1a — Per-material pipeline cache

`ForwardRenderPath` gains `m_mat_cache` (`HashMap<MaterialTemplate*, MatPipelineEntry>`) and `m_owned_mat_pipelines` (owning Array of compiled pipelines).

`get_or_compile_mat_pipelines(mat_template)`:
- Skips `PostProcess`, `Compute`, `Decal`, `UI` domain materials (only `Surface` matters for ForwardRenderPath).
- Reads `pass_shaders[DepthPrepass].vert` and `pass_shaders[Forward]` from the template.
- Each `PassShaderPair` holds `ResourceHandle<ShaderResource>` — resolved by the MaterialResourceLoader.
- Compiles a **depth-only pipeline** (vertex shader only, `color_format = Undefined`, `depth_format = D32Sfloat`) and a **color pipeline** (vert + frag, `color_format = B8G8R8A8Unorm`, `depth_format = D32Sfloat`).
- Both use the standard 48-byte interleaved vertex layout statics defined at file scope.

### v1b — Multi-pass shader selection

`PipelineResolver` gets a default no-op `begin_pass(PassType)` virtual method. `ForwardRenderPath` calls `m_resolver->begin_pass(PassType::DepthPrepass)` before the depth draw loop and `m_resolver->begin_pass(PassType::Forward)` before the color draw loop. This allows injectable resolvers (like `SandboxPipelineResolver`) to track which pass they are serving.

`DrawItem::material` and `Renderable::material` fields added (both `const MaterialInstance* material = nullptr`). `build_frame()` validation relaxed: accepts a renderable with `material != nullptr` even when `variant` is not valid; copies the material pointer into `DrawItem`. `build_frame()` returns false only when both material and variant are absent (or the vertex buffer is null).

### v1c — Depth-only prepass pipeline + smoke_depth_prepass

Both the material-path and the legacy-path draw loops in `ForwardRenderPath` now produce distinct depth-only and color pipelines. The depth prepass submits against the depth pipeline; the color pass against the color pipeline.

`smoke_depth_prepass.exe` (GPU/window): creates a Vulkan instance + device (gracefully skips if unavailable), creates descriptor allocator + `ForwardRenderPath`, runs one frame with an empty draw list, calls `device->wait_idle()`, exits 0.

### v1d — Default lit shaders

`engine/renderer/shaders/surface.vert`:
- Reads 48B interleaved vertex layout: `layout(location=0) in vec3 in_position`, `layout(location=1) in vec3 in_normal`, `layout(location=2) in vec2 in_uv0`, `layout(location=3) in vec4 in_tangent`.
- Uniform: `PerFrameUbo` at set=0, binding=0 (view/proj/view_proj/inv_view_proj + camera_pos_ws + viewport).
- Push constant: `PerDrawPush { mat4 model; }`.
- Outputs `VertexAttrs { vec3 position_ws; vec3 normal_ws; vec2 uv0; vec4 tangent_ws; }`.

`engine/renderer/shaders/surface.frag`:
- Includes `surface_data.glsl.inc` (shipped Phase 2.7) for `SurfaceData` + `crd_evaluate_surface()` contract.
- Implements `crd_evaluate_surface()` with: `base_color = vec3(1.0)`, `metallic = 0.0`, `roughness = 1.0`, `emissive = vec3(0.0)`, `occlusion = 1.0`.
- Lambertian diffuse: `L = normalize(vec3(0.5, 1.0, 0.5))`, `diffuse = max(dot(N, L), 0.0)`, ambient = 0.05.
- Output: `layout(location=0) out vec4 out_color`.

`assets/materials/default_lit.mat.toml`: `domain = "Surface"`, `alpha_mode = "Opaque"`, references surface.vert/frag.

### v1e — Sandbox 3D rendering

**SandboxPipelineResolver** (new class in `sandbox_layer.hpp`):
- `init(device, layout, runtime, variant, extent)` — stores pointers.
- `begin_pass(PassType)` — stores `m_current_pass`.
- `resolve_pipeline(handoff)` — calls `ensure_compiled` on first invocation, then returns `m_depth_pipeline` or `m_color_pipeline` based on `m_current_pass`.
- `ensure_compiled(handoff)` — iterates `handoff.modules` (`Array<ShaderModuleUsageDesc>`), calls `find_module(mod_usage.module)` (needs `.module` field — not the struct itself), uses `code_bytes()` to create `rhi::ShaderModule` objects, compiles depth-only and color `GraphicsPipeline` objects.

**SandboxLayer changes**:
- Constructor takes `crd::rhi::Device& device` (was not in the original).
- Compiles `surface.vert` + `surface.frag` via `crd::shader::create_runtime()` + `create_effect()` + `request_variant()`.
- Creates `m_desc_alloc` and `m_frp` (`ForwardRenderPath`); calls `m_resolver.init()` after layout is available.
- `upload_selected_shape()`: `device.wait_idle()`, regenerates mesh with `MeshResource cpu_mesh(&tmp)` (must pass allocator), uploads via `GpuUploader::upload_mesh()`.
- `render_scene(cmd, sc_image, frame_index)`: builds `look_at()` + reverse-Z `perspective()` (both local helpers in the anonymous namespace); submits a legacy-path `Renderable` (no material, uses `m_surface_variant`); runs `FrameGraph`; blits color RT → swapchain.

**Blit sequence in render_scene():**
```
ColorWrite → TransferSrc  (FRP color image)
Undefined  → TransferDst  (swapchain image)
blit_image(FRP color → swapchain, FRP extent, swapchain extent)
TransferDst → ColorWrite   (swapchain, ready for ImGui LoadOp::Load)
```

After render_scene(), `main.cpp` runs ImGui with `LoadOp::Load`, then transitions swapchain `ColorWrite → Present`.
