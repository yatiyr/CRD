# ADR-0005 — Math v1

**Date:** 2026-04
**Status:** Accepted
**Tags:** [math]

## Decision

- Column-major matrices (Vulkan / GL convention). `Mat * Vec`.
- Radians everywhere.
- Scalar first, SIMD later.
- `float` and `double` first-class. Templated backbone with named aliases.
- Quaternion: Hamilton, `xyzw`, identity `(0, 0, 0, 1)`.
- `Transform` ships in v1.
- Long-range slices M0–M9: M0–M5 shipped (foundations + core geometry);
  M6 SIMD, M7 dense, M8 sparse + iterative, M9 robust geometry — Phase 4.1.
