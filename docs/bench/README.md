# docs/bench — captured benchmark results (append-only)

<!-- doc-role: navigation -->
> Navigation; no independent live queue. Current work: [ROADMAP](../ROADMAP.md); current rules: [AGENTS](../../AGENTS.md).

Every measured benchmark board lands here as its own file, **at the time it is measured** — never quoted
from memory (SANITY #2/#5). This is the single home for numbers; session logs and system docs LINK here
instead of restating tables.

Method: [reference-class benchmarking policy](../PRINCIPLES_reference_class_benchmarking.md) and the [kernel mandate](../KERNEL-CRUSH-MANDATE.md).

**Naming:** `YYYY-MM-DD-<slice-or-module>-<subject>.md` (e.g. `2026-07-02-v14a-dtype-converts.md`).

**Each file carries:**
1. The exact machine/config (CPU, pinning, thread count, compiler + flags, peer versions), and for each Cerid arm
   its CPU level line (`cpu detected=... selected=... override=... kernel_cap=...`, ADR-0134 §8), which the
   harnesses print through `runtime/cpu_level_record` (and crd-bench and diag-overhead in their own output).
2. The harness used (script path — tracked under `scripts/`), so any board is re-runnable.
3. The full peer board — every peer measured, losses and ties included (SANITY #6/#9: a loss is an open
   bug, not a disclosure; N/A stated *with the check*).
4. The verdict line quoted by session logs / phase tables.
5. The host's load before and after (`python scripts/build-bench.py host`). Boards do not wait for a quiet host
   (user order, 2026-10-31): they run with `--allow-contended`, name the load, and judge by ratios of interleaved arms
   against the peers and the pre-row engine; a regression is real only if it holds across the interleaved repetitions.

Historical results (v5–v13 + the transcendental cluster) were retro-ported 2026-07-02 from the session
logs / phase tables (recorded numbers, not re-measured — each file carries the note). From v14 on, every
board is written here AT MEASUREMENT TIME — this is part of the per-slice Definition of Done for any
perf/crush claim (see [AGENTS](../../AGENTS.md#conduct--mandatory)).
