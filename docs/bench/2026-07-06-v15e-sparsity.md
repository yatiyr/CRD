# 2026-07-06 — v15-e: automatic sparsity detection + coloring + compressed recovery (crush)

**Scope status: COMPLETE.** Jacobian tracer + coloring + CSR recovery (crush) · Hessian 5-flag tracer + ε2-tiled
recovery (crush) · local (value+set) tracer. No C++ incumbent for detection — Julia's SparseConnectivityTracer.jl is
the only prior art; we bring it to deterministic, allocation-free C++. Hill & Dalle 2025 (arXiv:2501.17737).

**Coloring note (why no separate "star coloring" code):** every DISTANCE-2 coloring IS a valid star coloring — any
P4 `a-b-c-d` in a distance-2 coloring has a≠b, b≠c, a≠c (≥3 colors), which is the star property. So the shipped
distance-2 coloring already colors symmetric Hessians validly. The *minimal* star coloring buys fewer colors only for
the DIRECT recovery `B = H·S`, and that needs the vector HVP = forward-over-reverse = **v16-e** (research §B). The
forward-only Hessian here uses ε2-tiled recovery, which needs no coloring — so star coloring ships with its actual
consumer in v16-e (not dead code in v15-e).

## What shipped
- **`sparsity.hpp` — Jacobian tracer.** `JacPattern<W>` carries an inline W-word `u64` bitset of input dependencies;
  seed i → {i}; `+`/`-`/`*`/`/` union (word-wise OR — branch-free, O(N/64), zero alloc, **deterministic**, unlike
  ColPack/Julia hash-sets); nonlinear unary copies; a constant is ∅. One abstract pass → each output row's nonzero
  columns.
- **`sparse_jacobian.hpp` — pipeline.** `trace_jacobian` → `distance2_color` (greedy distance-2, VALID by test:
  no two co-occurring columns share a color; tridiagonal → 3) → `sparse_jacobian_csr` (ncol JVP sweeps via the v15-d
  driver → compressed B, then **O(nnz)** CPR recovery into CSR). Allocation-free (caller owns every span).
- **`sparsity_hessian.hpp` — Hessian 5-flag tracer.** `HessPattern<MaxN>` carries a grad bitset + a pair bitset
  {(i,j)|∂²≠0}; the verified second-order (Faà di Bruno) propagation — inherited ∨ self(∂²₁,∂²₂) ∨ cross(∂²₁₂),
  self/cross being O(k²) outer products (the Θ(k²n) total). Pairs canonicalized i≤j.

## Correctness (`test_sparsity.cpp`, all green)
- Jacobian pattern == analytic (tridiagonal); distance-2 coloring valid + minimal (3 colors); **compressed recovery
  == dense Jacobian** (tridiagonal + arrowhead, bit-exact); global tracer keeps structural zeros (`x*0`).
- **Hessian 5-flag interaction battery:** `x*y`→cross(0,1) only; `sin(x)`/`x²`→self(0,0); `x+y`→none;
  `x²+y²`→(0,0),(1,1) not (0,1); `(x0+x1)²`→dense. Exactly the paper's semantics.

## Local tracer (`JacLocal<W>` — value + set)
Point-dependent, SPARSER: value-gated multiply drops `x*0`/`0*x`/`sin(0*x)`; `min`/`max`/`abs` and branches resolve on
the live value (the global tracer can't). Tested: local drops `x0*0` (global keeps {0,1}); `min(0.3,0.8)`→branch-0
deps; `|−0.4|`→0.4 + deps. ⚠ point-dependent — never cache across inputs.
