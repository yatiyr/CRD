## What shipped (engine/hesap-tensor/include/crd/hesap/tensor/sparse.hpp + sparse_mttkrp.hpp)

- **SparseCoo<T>**: canonical coordinate format (SoA u32 mode planes, lexicographically
  sorted, duplicates summed) + **SparseCooBuilder** mirroring hesap-sparse's
  TripletBuilder determinism contract (stable LSD counting sort, insertion-order
  duplicate summation — compress() bit-reproducible; gated BIT-EXACT against numpy).
- **SparseCsf<T>**: the SPLATT mode tree (any level→mode order), concatenated per-level
  fids/fptr storage; `coo_to_csf` + `coo_reorder` (counting-sort resort).
- **mttkrp** (CSF) + **mttkrp_coo** (reference walk, exact same op sequence ⇒ CSF==COO
  **bit-identity gated**); **contract_mode** (mode-n product into the dense tensor
  layout); **sparse_add/mul** (union/intersection), **sparse_mul_dense/add_dense/to_dense**;
  **reduce_sum/max** total + per mode (dense semantics: implicit zeros participate in
  max) + CSF root-mode forms — all riding the module's existing pinned-order reduction
  core (`reduce.hpp detail::block_partial`, SANITY #8 reuse; deterministic f(n)-only tree).
- Determinism moat: all parallel drivers partition by grain = f(shape/nnz) ONLY with
  disjoint outputs (MTTKRP root fibers, TTM mode-0-run-snapped ranges) or fixed-count
  partial buffers folded in task order (TTM contracted-root case) ⇒ `{1,2,4,8,16}`
  workers **bit-identical, gated** on MTTKRP + both TTM paths.

## The three performance lessons (each flipped a losing row)

1. **MTTKRP 20 ms → 10.1 ms — registers, not staging buffers.** The first CSF walk
   staged each fiber's accumulator in a scratch row (memset + load/store per leaf
   axpy). SPLATT's 16 ms proved headroom; the fix keeps the R=16 accumulator in FOUR
   ymm registers across the fiber's leaves and fuses the parent-factor multiply into
   the store-back. Op-for-op the same fma chains ⇒ still bit-identical to the COO
   reference (gates unchanged).
2. **TTM mode-1 130 ms → 33 ms — stage the slice, then transpose.** Scattering F=16
   strided elements per nonzero touches 16 cache lines each. Staged kernel: per prefix
   run (mode-0 fiber), accumulate into a `[suffix, F]` tile with CONTIGUOUS 128-byte
   axpys, then one blocked transpose into the contiguous out slice. Same per-element
   chain order (bit-identical to the scatter path, which remains the fallback for
   oversized suffixes).
3. **add/mul 68/56 ms → 31/22 ms — pack once, merge branchless.** (a) Plane-major
   key packing was a 3-pass read-modify-write over an 80 MB array (~600 MB traffic) —
   entry-major single-pass writes each key once; tuples fitting 32 bits use u32 keys
   (half the traffic). (b) The merge's ternary selects compiled to data-random BRANCHES
   (predictor-hostile); the A/B probe measured ternary 39.3 ms / branchy 36.9 ms /
   **forced bit-mask selects 26.8 ms**. The shipped merge selects values by integer
   masks and advances cursors by setcc arithmetic — no branch in the loop body. The
   absent-side value contributes an explicit +0.0, which is EXACTLY the densified
   reference's arithmetic (bit-gated).
