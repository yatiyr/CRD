# 2026-07-07 -- v16-k (part 2): KAN (Kolmogorov-Arnold network) vs efficient-kan

**What shipped (`kan.hpp`):** a KAN with the **Efficient-KAN restructuring**. Each edge (i,j) carries a learnable 1-D
function `φ_ij(x) = wb_ij·silu(x) + Σ_g ws_ijg·B_g(x)` (base + degree-3 B-spline). The naive form re-evaluates every
edge's spline separately; the KEY restructuring exploits that the B-spline basis `B_g(x_i)` depends only on the INPUT
`i` (not the output `j`), so the basis is computed **once per input** (`kan_forward` builds `Bmat`=din×nbasis) and the
layer is two matmuls `y = Wb·silu(x) + Ws·vec(B(x))`, reused across all outputs. `kan_vjp` uses the B-spline derivative
(a degree-(p−1) combination) so deep KANs differentiate through the edge nonlinearity.

## Gate (`test_kan.cpp`, win-debug, 125 asserts)
- **B-spline basis is a partition of unity** (`Σ_g B_g(x) = 1`, `<1e-12`) and its analytic derivative matches central FD.
- **The efficient forward is BIT-IDENTICAL to the naive per-edge form** (exact `==`).
- **`kan_vjp` == central FD** for the base weights, spline coeffs, AND the input gradient (deep-KAN backprop).
- **A 2-layer KAN [2→4→1] fits a coupled target** `sin(2x+1.5y)` (loss reduced >40%) and **replays bit-for-bit**.
