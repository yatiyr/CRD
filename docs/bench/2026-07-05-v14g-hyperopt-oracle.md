## 4. Determinism note (the moat, structural)

cotengra's default stack is non-reproducible by construction: unseeded optuna-TPE, trial
functions drawing from python's GLOBAL rng, and parallel futures feeding the sampler in
completion order. Ours is counter-keyed (SplitMix64 per (seed, trial, stream)) — bit-identical
results at ANY worker count by design; the C++ port inherits this + caller-workspace/no-throw/
bounded-iteration (ADR-0095 pillars).
