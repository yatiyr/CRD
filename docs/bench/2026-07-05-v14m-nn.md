## The three tiers (nn.hpp `NnQuantTier`)

- **F32** — full precision.
- **Q8Block32 (the DEFAULT quantized tier)** — ggml Q8_0 block-32 on weights AND
  activations: byte-interop with the frozen refs / llama.cpp, per-block-32 scale
  granularity, the pinned lane-parallel kernel. Pick it for CERTIFICATION: frozen-weight
  byte-exactness, ggml ecosystem interop, finest scale granularity.
- **I8PerTensor (the THROUGHPUT tier)** — per-tensor symmetric i8 weights (+ precomputed
  column sums) x per-row ASYMMETRIC u8 activations (the ort DynamicQuantizeLinear /
  MatMulInteger scheme class): weights repacked at load to the MLAS-style
  [8-outputs x 4-k-bytes] interleave so ONE `dpbusd` accumulates 8 outputs (no horizontal
  reduction), 4 rows share every weight load, and the epilogue is an exact integer
  zero-point correction + one fma. Pick it for raw speed; on this corpus it is also the
  MOST accurate quantized path (u8 captures the full post-relu range).

Both tiers: run-twice bit-identical, `{1,2,4,8,16}` worker moat, allocation-free infer,
scalar-mirror bit-identity (all gate-enforced; 18 cases / 5,194 asserts).

## The optimization ledger (what moved the boards, all gate-preserved)

Starting point -> shipped, ns/sample: mlp f32 246->218 · mlp quantized 1418->155 · cnn
f32 6560->2084 · cnn quantized 2406->2060. In order:
1. **Q8 scale hoisting** (weight scales pre-widened f32 at load, row scales once per row)
   + **vectorized activation quantizers** (AVX2, gate-enforced BIT-IDENTICAL to the scalar
   references incl. roundf half-away and +-0 lanes; 272 -> 14 ns/row): q8 mlp 1418 -> 630.
2. **relu fusion** into linear/conv epilogues (finalize scan; cache-hot, lane-identical).
3. **direct 3x3/s1/p1 conv kernel** (staged padded rows, 8 oc x 8-wide columns per
   register block) — the per-element fma CHAIN is IDENTICAL to im2col+GEMM (gated
   bit-exact): conv2 3098 -> 1111 ns/img standalone.
4. **conv+relu+maxpool2x2 fusion** (pooled rows only touch memory): cnn@4096 2309 -> 1974.
5. **the Q8_0 tile kernel** (4-then-8 outputs share each activation load; exact i32 lane
   partials — maddubs/madd or bit-identical `dpbusd`; one hadd reduction per 4 outputs;
   pinned sum tree mirrored exactly by the scalar fallback): q8 mlp 630 -> 398.
6. **vectorized 2x2/s2 maxpool**: 1.76 -> 0.3 ms at cnn@4096.
7. **COMPILE-TIME tile templates** (the runtime-bound 3-instruction inner loops were
   issue-width-bound on loop micro-ops; the batched.hpp switch-dispatch pattern):
   q8 mlp 398 -> 342.
8. **the I8PerTensor tier** (u8-asym activations x packed i8 weights): first cut
   (row-major, symmetric i8 activations) 290; 8 accumulator chains 257; u8-asymmetric +
   zero-point correction 223; the PACKED MLAS-structure kernel (one dpbusd = 8 outputs,
   4-row weight-load sharing, no horizontal reduction) **155 ns/sample** — each step
   located by stage-isolated timing (fc1 dots were 97 ns/row of tile fixed costs at k=64
   before packing; the 8-wide-block epilogue killed the hadd chains entirely).

## Moat pillars (all gate-enforced — 18 cases / 5,194 asserts, green on
## -mavx2, -mavxvnni, AND -fsanitize=address,undefined builds)

- torch value parity <= 1e-6 f32, both models, all rows (measured 6e-8).
- Q8_0 weights: quantize-on-load **byte-exact** vs the frozen refs (D-v14m-1: the frozen
  corpus rounds half-to-EVEN on the f16-ROUNDED inverse scale — dtypes.hpp's ggml
  transcription differs on 150/16416 q values; the loader implements the frozen-ref
  semantics, documented in nn.hpp).
- Both Q8_0 weight-load paths (quantize-on-load vs raw .q8/.q8s) bit-exact against each
  other, blocks AND outputs, both models.
- Quantized inference (BOTH tiers): run-twice bit-identical; bounded error vs f32 with
  argmax preserved on every corpus row; `{1,2,4,8,16}` workers bit-identical; ZERO
  allocations at infer (counting-allocator gate, all six nets).
- Kernel bit-identity: conv2d/linear bit-exact vs the k-ordered fma-chain references; the
  vectorized quantizers bit-identical to their scalar references (incl. +-0, zero-row,
  huge, tiny-scale, and all-positive adversaries); the I8 PACKED runner kernel bit-exact
  vs the row-major reference op AND the scalar integer formula (masked-tail block
  covered, n = 13).
