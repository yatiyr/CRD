# 2026-07-06 — v15-g: Taylor-mode jets + the Taylor ODE integrator — CRUSH

**Headline crush (unambiguous, no caveat): high-order derivatives.** Taylor-mode returns EXACT order-K derivatives in
O(K²); finite differences are garbage at high order (÷hᵏ cancellation) and nested first-order AD is O(2^K). There is
no regime where Taylor-mode loses this — it is exact and fast, period. The Taylor ODE integrator (built two ways: a
generic order-by-order one AND a TIDES-class **O(K²)-per-step taped** integrator) then crushes on its own job —
high-precision integration — reaching accuracies adaptive RK cannot touch and running an order of magnitude faster
there.


**What shipped:** `taylor.hpp` — `TaylorJet<T,K>` (length-(K+1) normalized coefficients a[k]=f^(k)/k!) driven by the
Griewank-Walther master recurrence `y_k=(1/k)Σ(k−i)f_{k−i}w_i` (w = the function's derivative series): +, −, *
(Cauchy product), /, exp, log, sin/cos (coupled), tanh, sqrt, pow — the whole order-K series in O(K²), NO FFT
multiply. `taylor_ode.hpp` — the generic Taylor-series ODE integrator (order-by-order build + robust adaptive step:
min over the last coefficients + step-growth cap, guarding the oscillatory near-zero-coefficient divergence trap +
Horner advance). `taylor_tape.hpp` — the **O(K²)-per-step taped integrator**: record the RHS's op graph ONCE via
operator overloading, then propagate every node's coefficients order-by-order (one length-m convolution per op at
order m) — a ~K× speedup that is what lets Taylor beat adaptive RK below the crossover. Verified vs the analytic
Taylor series + closed-form ODEs; the taped result is checked bit-close to the generic one.
