the wall-clock gap.

## How the win was found (the first board LOST every row — rule #9, solve it)

First measurement: **0.10–0.52x on every row** (e.g. 64^3 CP 326.55 ms vs 34.22). The atom
probe (`scratchpad probe`, best-of-5) decomposed the loss in one pass:

| atom (64^3 regime) | ms |
|---|---|
| ALS sweep loop, 10 iters (mttkrp+solve, hoisted unfolds) | 6.03 |
| one exact bidiagonal SVD of a 64x4096 unfolding (x3 per init) | **117.18** |
| one MTTKRP mode-1 r16 | 0.19 |
| one 2-ttm projection chain | 0.34 |

The ALS engine was already 5x faster than TensorLy's whole run — the ENTIRE loss was the
factor kernel: bidiagonal SVD of short-fat unfoldings. Fixes, each re-gated:

1. **The Gram kernel (D(v14j)-4, the TuckerMPI-standard):** leading left singular vectors
   via G = A A^T (one gemm pass) + hesap-dense `eig_sym` — 117 ms -> **0.67 ms** (175x).
   Directions with sigma <= sqrt(eps)*sigma_max lose angle accuracy but carry no
   reconstruction mass; all 191 oracle/recovery/moat assertions stayed green, including the
   1e-12 exact-recovery rows.
2. **Batched Philox sketch** (`philox_gaussian_fill`): the per-sample keyed draw (fresh RNG
   + 6 scalar blocks each) became a chunked ride of `PhiloxRng::fill`'s AVX2 8-block path —
   BIT-EQUAL to the keyed definition (gated sample-for-sample) — sketch 2.4x faster.
3. **Gram-operator power iteration** (rows <= 256 dispatch): the classic HMT power pass
   cost two full passes over A plus two [cols x ell] Householder QRs (~2 ms each, measured
   the dominant randomized cost); the restructured form powers G on the small side with
   ell-sized QRs and takes the Ritz block H = Q^T G Q — randomized 128^3 row 327 -> 115 ms.
   The classic form remains (and is gated) for the tall-rows regime where G is rows^2.
