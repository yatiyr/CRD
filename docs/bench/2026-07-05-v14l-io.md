## Why (mechanisms, all deterministic — identical output bytes)

- **Single-pass streaming**: `npy_read_file`/`npy_write_file`, `SafetensorsWriter::finish_file`,
  and `safetensors_read_tensor_file` fread/fwrite payloads DIRECTLY between the file and tensor
  storage — no whole-file staging Array (which doubled every copy; the first cut measured
  0.61x on writes and 0.59x on reads before this).
- **In-place overwrite** (`CFile::Overwrite`): open `r+b` + truncate-at-end instead of
  truncate-open. Truncation evicts the file's page-cache pages; re-allocating them measured
  2.0 vs 7.2 GB/s on a cached 512 MB rewrite (micro A/B in the session log). numpy truncates.
  Cold first-writes (no existing file) are ~2.5 GB/s for both sides — the win there is the
  staging-buffer elimination only.
- **safetensors read**: the streaming single-tensor path (`safetensors_read_tensor_file`)
  parses the JSON header, seeks, and freads one tensor straight into owned storage — the
  ML-weights access pattern; python's equivalent (mmap + clone) pays page-in + copy.

## Correctness anchors riding the same binaries

- Bench read-backs memcmp'd against the source tensor (bit-exact) every run.
- The full v14-l gate: 655 assertions / 14 cases (`build/crd_io_gate.sh`) + the python oracle
  check — 39/39 round-trip verifications PASS (numpy/torch/safetensors read OUR files bit-exact;
  we read THEIRS bit-exact, including bf16 + fp8-e4m3 safetensors, npz STORED + DEFLATE, npy
  v1.0/v2.0/0-d/empty). Our npy v1.0 writer output is **byte-identical** to `np.save` on all
  17 corpus cases.

## npz-DEFLATE status (loud, per the slice contract)

- npz WRITE = STORED members — exactly what `np.savez` itself emits (compress_type 0 verified).
- npz READ = STORED **and** DEFLATE (`np.savez_compressed`) — full RFC 1951 inflate implemented
  in `detail/io_zip.hpp`, CRC-32 gated on every member.
- npz DEFLATE **write** = N/A (no deflate compressor in the engine; zstd is the house codec).
  Check: numpy reads our STORED npz bit-exact (oracle board rows "npz roundtrip member a/b/c" +
  "npz members are STORED"). Nothing in the numpy round-trip contract requires DEFLATE output.
