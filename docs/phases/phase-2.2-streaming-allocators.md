## Pinned decisions (ADR-0085)
- **D1** stable-address VM-reserve is the CPU strategy (no relocating CPU heap).
- **D2** streaming/residency strictly out of the deterministic sim path (ADR-0063); resident data bit-identical; addresses process-private.
- **D3** thread-safety per-allocator + explicit (Ring + Gpu thread-safe; VM + TLSF single-threaded per arena).
- **D4** GPU residency/defrag policy injected (`IResidencyPolicy`/`IDefragPolicy`), not baked — render-path-agnostic.
- **D5** malloc removed at the root (VM is the page source; `default_allocator()` bootstrap-only).
- **D6** no owning STL; crd types; units at the API surface.
- **D7** reuse the shipped pipeline (ResourceManager budgets/eviction, async I/O, jobs) — this cluster adds the missing *allocators*.
